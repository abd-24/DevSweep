# DevSweep

AI-assisted developer workspace cleaner.

## Goal

Detect:

- Temporary files
- Forgotten builds
- Duplicate assets
- Unused folders
- Stale repositories

and safely clean them.

## Tech Stack

Python

Phase 1:
- Rule Engine
- File Scanner
- Report Generator

Phase 2:
- GUI

Phase 3:
- AI Recommendation System

## Run

```bash
python main.py
```
